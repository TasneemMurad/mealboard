# Mealboard - Recipe Browsing App

Mealboard is a responsive React web application built as part of the Web Applications Programming and Engineering (WAPE) course (Milestone 1). It allows users to browse, search, filter, and sort recipes seamlessly across desktop and mobile devices.

## Team Members
- **Tasneem Murad**

## Features (Milestone 1)
- **Recipe Browsing Grid:** Responsive card layout displaying recipe images, titles, cuisine types, difficulty levels, prep times, ratings, and authors.
- **Search & Filter Controls:** Real-time search by recipe title, filtering by cuisine, and sorting by preparation time (shortest/longest first).
- **Navigation & Routing:** Client-side routing using `react-router-dom` with active link highlighting (`/`, `/login`, `/register`, `/about`).
- **Authentication UI:** Interactive `Login` and `Register` forms with controlled inputs, basic validation, and confirmation feedback views.
- **About Page:** Overview of the application and development team.

## Tech Stack
- **Frontend:** React, React Router DOM, Vite, CSS3 (Grid & Flexbox)

## How to Run Locally
1. Navigate to the client directory:
cd client

2. Install dependencies:
npm install

3. Start the development server:
npm run dev
